{% trans "Politique de confidentialité" %}

{% trans "Dernière mise à jour : janvier 2026" %}

{% blocktrans trimmed %} Numeria Institute (numeriainstitute@gmail.com) s'engage à protéger la vie privée de ses utilisateurs. La présente politique décrit quelles données nous collectons, pourquoi nous les collectons et comment vous pouvez exercer vos droits. {% endblocktrans %}

{% trans "1. Données collectées" %}

{% trans "Lors de votre inscription et utilisation de la plateforme, nous collectons les informations suivantes :" %}

  • {% blocktrans trimmed %}Identité : nom, prénom, adresse e-mail.{% endblocktrans %}
  • {% blocktrans trimmed %}Profil : pays, ville, niveau d'études, domaine d'intérêt.{% endblocktrans %}
  • {% blocktrans trimmed %}Progression pédagogique : cours suivis, leçons terminées, exercices soumis, certificats obtenus.{% endblocktrans %}
  • {% blocktrans trimmed %}Données de candidature : CV, lettre de motivation, relevés de notes (pour les dossiers d'admission uniquement).{% endblocktrans %}
  • {% blocktrans trimmed %}Données de paiement : référence de transaction (nous ne stockons pas les numéros de carte bancaire).{% endblocktrans %}
  • {% blocktrans trimmed %}Données techniques : adresse IP, type de navigateur, pages visitées (via journaux serveur).{% endblocktrans %}

{% trans "2. Utilisation des données" %}

{% trans "Vos données sont utilisées exclusivement pour :" %}

  • {% trans "Gérer votre compte et vous authentifier sur la plateforme." %}
  • {% trans "Suivre et afficher votre progression dans les cours." %}
  • {% trans "Générer et délivrer vos certificats de réussite." %}
  • {% trans "Traiter vos dossiers de candidature aux programmes d'admission." %}
  • {% trans "Améliorer le contenu et les fonctionnalités de la plateforme." %}
  • {% trans "Vous envoyer des notifications liées à votre activité (réponse à candidature, confirmation de paiement)." %}

{% trans "Nous ne vendons, ne louons ni ne partageons vos données personnelles avec des tiers à des fins commerciales." %}

{% trans "3. Cookies" %}

{% trans "Numeria Institute utilise des cookies techniques strictement nécessaires au bon fonctionnement du site :" %}

  • {% blocktrans trimmed %}Session Django : maintient votre connexion entre les pages.{% endblocktrans %}
  • {% blocktrans trimmed %}CSRF token : protège les formulaires contre les attaques de type falsification de requêtes.{% endblocktrans %}
  • {% blocktrans trimmed %}Préférence d'affichage : mémorise votre choix de mode clair/sombre (stocké dans localStorage, pas un cookie).{% endblocktrans %}

{% trans "Nous n'utilisons pas de cookies publicitaires ni de traceurs tiers (Google Analytics, Facebook Pixel, etc.)." %}

{% trans "4. Vos droits" %}

{% trans "Conformément aux principes généraux de protection des données, vous disposez des droits suivants :" %}

  • {% blocktrans trimmed %}Droit d'accès : obtenir une copie des données vous concernant.{% endblocktrans %}
  • {% blocktrans trimmed %}Droit de rectification : corriger des informations inexactes ou incomplètes.{% endblocktrans %}
  • {% blocktrans trimmed %}Droit à l'effacement : demander la suppression de votre compte et de vos données.{% endblocktrans %}
  • {% blocktrans trimmed %}Droit à la portabilité : recevoir vos données dans un format structuré.{% endblocktrans %}
  • {% blocktrans trimmed %}Droit d'opposition : vous opposer à certains traitements de vos données.{% endblocktrans %}

{% blocktrans trimmed %} Vous pouvez exercer ces droits directement depuis votre profil (section Supprimer mon compte) ou en nous contactant. {% endblocktrans %}

{% trans "5. Conservation des données" %}

{% trans "Vos données sont conservées aussi longtemps que votre compte est actif. En cas de suppression de compte, vos données personnelles sont effacées dans un délai de 30 jours. Les données de transaction sont conservées 5 ans à des fins comptables et légales." %}
